The server is running, but the game client hasn't been built yet. Build it one of two ways, then refresh this page:

  • With Docker (no Unity install needed): run task license:activate once to get a free Unity license in your browser, then task client:build.
  • With the Unity editor: open the Shadowfall folder and choose Shadowfall > Build WebGL from the menu bar.

Either way, the build is written to server/public. See docs/deployment/docker-client-build.md.
